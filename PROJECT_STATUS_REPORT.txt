     - Need image upload, or paste URLs?
  5. VERIFICATION
     - Public verification (anyone) or restricted?
     - Should verified cert open a printable PDF?

     - Where to host DB? (Postgres/MySQL/MongoDB)
     - Deployment target (Vercel / own server)?
